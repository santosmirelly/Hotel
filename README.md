# SistemaCLI-

Sistema de gerenciamento de quartos de um hotel desenvolvido em Python.

## Funcionalidades

- Realizar check-in
- Exibir mapa de quartos
- Alterar status dos quartos
- Realizar check-out
- Liberar quarto após limpeza
- Calcular o valor total da hospedagem
- Validação de idade do hóspede
- Controle de quartos livres, ocupados e em limpeza

## Status dos quartos

- Livre
- Ocupado
- Em limpeza

## Tecnologias utilizadas

- Python
- Git
- GitHub

## Projeto

Projeto desenvolvido como atividade prática do curso de Informática.
